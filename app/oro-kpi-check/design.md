# ORO KPI CHECK — Design

## Purpose

顧客管理シートから算出した正しいおろチームKPIをDiscord投稿形式でコピーし、メンバーが自己申告した投稿との差分だけを短時間で確認する。

## Visual direction

- 業務用の検算画面として、明るい紙面色と濃紺のヘッダーを使う。
- 過大報告は青、過小報告は赤、未報告は橙で統一する。
- 正しい項目や正しいメンバーは比較結果から隠し、注意が必要な場所だけを残す。
- 数字を最優先にし、装飾アニメーションやCanvas/WebGL効果は使用しない。
- PCは横並び、スマートフォンは一列のメンバーカードにする。

## Core layout

1. ヘッダー: 対象月、データ取得状態、対象10名。
2. 正しい投稿文: Discord向けテキストと全文コピーボタン。
3. 報告貼り付け: クリップボード貼り付け、照合、クリア。
4. 差分結果: ズレがあるメンバーと項目だけを表示。

## Interaction states

- Loading: 対象月のデータ更新中をボタンとステータスで表示。
- Success: 全員一致の場合は緑の完了パネル。
- Difference: `報告値 - 正解値` を大きく表示。
- Missing: メンバーの投稿が無い場合は橙の「報告なし」。
- Error: データ取得・クリップボード失敗を日本語で表示。
