# ブラウザ操作ポリシー(Kimi webbridge 優先)

このリポジトリでブラウザ操作を行うときは、**Kimi webbridge を第一選択**とする。

## 手順

1. **ツール検出**: まず ToolSearch で `kimi webbridge`(または `+kimi`)を検索し、Kimi webbridge MCP サーバーのツール(`mcp__kimi*` / `mcp__*webbridge*`)のスキーマをロードする。
2. **操作実行**: ページ遷移、クリック、入力、スクリーンショット取得などは Kimi webbridge のツールで行う。
3. **結果確認**: 操作後は必ずスクリーンショットか DOM の状態で結果を確認してから次の操作に進む。

## フォールバック

Kimi webbridge の MCP サーバーがこのセッションに接続されていない(ToolSearch で見つからない)場合のみ、次の順で代替する。

1. Playwright(Chromium は `/opt/pw-browsers/chromium` にプリインストール済み。`playwright install` は実行しない)
2. WebFetch(閲覧のみで十分な場合)

代替手段を使った場合は、その旨をユーザーへの報告に含めること。

## 注意事項

- ログイン情報や個人情報を含む画面のスクリーンショットを外部に送信しない。
- フォーム送信・購入・投稿など取り消しが難しい操作は、実行前にユーザーに確認する。
- `npm run dev` で起動するローカルアプリ(Next.js)の動作確認もこのポリシーに従う。
