## Web / LP / Artifact

### 内容

- [ ] `<title>` が具体的（「Levela」だけで終わっていない）
- [ ] `meta description` がある（120字前後）
- [ ] OGP画像・OGPタイトル・OGP説明がある
- [ ] `<html lang="ja">`
- [ ] favicon がある
- [ ] 見出しが `h1` → `h2` → `h3` の順（飛ばしていない）。`h1` は1つ

### 表示

- [ ] 375px / 768px / 1440px で崩れない（**実際に開いて確認**）
- [ ] ヒーロー見出しが意図しない位置で折り返していない
- [ ] ヘッダーメニューがスマホで開閉する
- [ ] 表・グラフが横溢れせず、内側でスクロールする
- [ ] 画像に `alt` がある（装飾画像は `alt=""`）
- [ ] 画像に `width`/`height` かアスペクト比があり、読み込み時にガタつかない
- [ ] リンク・ボタンにホバーとフォーカスの見た目がある
- [ ] キーボードのTabだけで主要導線をたどれる
- [ ] `prefers-reduced-motion: reduce` で移動アニメーションが止まる

### 動作

- [ ] リンク切れがない（特にフッターと外部リンク）
- [ ] フォームがある場合、送信先が正しく、送信後の表示がある
- [ ] コンソールにエラーが出ていない
- [ ] `npm run lint` と `npm run build` が通る（このリポジトリの必須手順）
- [ ] Lighthouse を実行し、Performance / Accessibility / SEO を確認した
