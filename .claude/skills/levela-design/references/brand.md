## 1. 色

### コア3色

Levelaは**墨・赤・紙**の3色でできている。ロゴがそう作られている。

| トークン | 値 | 意味 |
|---|---|---|
| `ink` | `#231815` | 温かみのある黒。Levelaの本体。文字・主ボタン・暗背景の基調 |
| `accent` | `#E50012` | ロゴ赤。**注意を1点に集める**ためだけの色 |
| `paper` | `#FFFFFF` | 基本の紙 |

赤は面積を持たせない。**1画面・1スライドに1箇所**が基本。
「重要な数字」「唯一のCTAの下線」「ロゴ」のどれか1つ。
2箇所以上に出た瞬間、どちらも重要でなくなる。

### 紙（明背景の3段）

スプラッシュのグラデーションから取った、純白→生成りの3段。

| トークン | 値 | 用途 |
|---|---|---|
| `paper-0` | `#FFFFFF` | 基本背景、カード面 |
| `paper-50` | `#FFFDFA` | わずかに温かい面。広い背景に使うと硬さが取れる |
| `paper-100` | `#F6F2EA` | 一段沈めた面。セクション区切り、コードブロック、表のヘッダ |
| `paper-200` | `#ECE6DC` | さらに沈めた面。ごく控えめに |

### 墨のランプ（文字と暗背景）

| トークン | 値 | 用途 | 白地コントラスト |
|---|---|---|---|
| `ink-950` | `#231815` | 本文、見出し | 17.31:1 |
| `ink-800` | `#3A2C27` | 暗背景の一段上げた面 | — |
| `ink-600` | `#5C4B44` | 副次的な文字、注釈 | 8.25:1 |
| `ink-500` | `#6B5A52` | 弱い文字の下限。**これより薄い色で文字を置かない** | 6.54:1 |
| `ink-400` | `#8B7A72` | アイコン、装飾、プレースホルダー（文字本体には使わない） | 4.10:1 |
| `ink-200` | `#C9BFB8` | 装飾罫 | 1.81:1 |
| `ink-100` | `#E7E1D8` | ごく薄い区切り | — |

### 真鍮（brass）

| トークン | 値 | 用途 |
|---|---|---|
| `brass` | `#BAA279` | **暗背景専用の上質感。** 罫、微光彩、小さなラベル |

スプラッシュの `rgba(186, 162, 121, 0.18)` の光彩がこの色。
**白地で2.46:1しかない**ので、明背景の文字・アイコンには絶対に使わない。
明背景で真鍮感を出したいときは、`#BAA279` を透明度0.15前後の**面や罫**として敷く（文字にはしない）。

### 意味を持つ色

| トークン | 明背景 | 暗背景 | 用途 |
|---|---|---|---|
| `success` | `#0F7B5A` | `#4CC79B` | 達成、正常 |
| `warning` | `#8F5A00` | `#E8B45C` | 注意、要確認 |
| `danger` | `#E50012` | `#FF6B5E` | エラー、破壊的操作 |
| `danger-text` | `#B3000E` | — | 明背景で赤の小さい文字を置くとき（7.18:1） |

**`danger` はブランド赤と同じ色。** これは意図的。
Levelaにおいて赤は常に「ここに注意を向けろ」を意味し、装飾では決して使わない。
だから「強調の赤」と「危険の赤」が同じでも意味が衝突しない。

## 2. モード選択（明 / 暗）

どちらを使うかは `design.md` で最初に決める。混ぜない。

### 明（paper）— 既定

対外的なもの全部。LP、コーポレート面、スライド資料、配布物、Markdown由来のHTML。

```
背景 paper-0 / paper-50    文字 ink-950
副文字 ink-600             罫 ink-100
主ボタン 塗り ink-950 / 文字 #FFFFFF   ← 赤ではない
副ボタン 枠 ink-200 / 文字 ink-950
```

### 暗（ink）— 業務画面

ダッシュボード、管理画面、長時間見る画面。

```
背景 #171010              面 #231815        一段上の面 #3A2C27
文字 #F6F2EA (16.82:1)    副文字 #B9AAA3 (8.36:1)
罫（装飾） rgba(246,242,234,0.12)
罫（操作可能な要素の境界） rgba(246,242,234,0.32)  ← 3:1を満たすために必要
アクセント brass #BAA279 (7.63:1) / 注意 #FF6B5E (6.72:1)
```

暗モードでは真鍮が主役になる。ネオン（teal / cyan / 蛍光緑）は使わない — Levelaの色ではない。

## 4. タイポグラフィ

### Web / Artifact

- 欧文・数字: **Geist Sans**（`--font-geist-sans`）
- 等幅: **Geist Mono**（`--font-geist-mono`）— 数値の桁を揃える表、コード
- 和文: OS標準に委ねる（`system-ui` フォールバック）。`lang="ja"` は必須

数値を並べる表・KPIでは Geist Mono か `font-variant-numeric: tabular-nums` を使う。
桁がガタつく表は、それだけで信頼できなく見える。

### 資料（pptx）/ 画像生成

- 和文: **Yu Gothic**（`YuGothB.ttc` 見出し / `YuGothM.ttc` 本文）
- 入手できない環境のフォールバック: **Meiryo UI**

### スケール（明背景・Web）

| 役割 | サイズ | 太さ | 字間 | 行間 |
|---|---|---|---|---|
| ヒーロー見出し | 44–64px | 700 | -0.02em | 1.15 |
| セクション見出し | 28–32px | 700 | -0.01em | 1.25 |
| 小見出し | 18–20px | 600 | 0 | 1.4 |
| 本文 | 16px | 400 | 0 | 1.75 |
| 注釈 | 13–14px | 400 | 0 | 1.6 |
| ラベル | 12px | 600 | 0.06em | 1.3 |

和文本文の行間は **1.75** を守る。欧文の1.5をそのまま持ってくると和文は詰まって読めない。
大きい見出しほど字間を詰める（`-0.02em`）。詰めないと間延びする。

## 5. 余白・角丸・影・罫

### 余白

4の倍数。`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128`

セクション間は最低 `64px`（スマホ `48px`）。**余白をケチると即座に安く見える。**
迷ったら広いほうを取る。

### 角丸

| 対象 | 値 |
|---|---|
| 主ボタン・チップ | `999px`（完全な丸み） |
| カード・パネル | `12px` |
| 入力欄 | `10px` |
| 画像・サムネイル | `8px` |
| 表・大きな面 | `0`（角丸にしない） |

ボタンのピル形状はスプラッシュ実装由来。Levelaの手触りの一部なので変えない。

### 影

物理的に矛盾しない影。色は墨を透過させる（黒の生影は使わない）。

| 段 | 値 |
|---|---|
| 浮き（カード） | `0 18px 36px rgba(35, 24, 21, 0.10)` |
| 主ボタン | `0 18px 36px rgba(35, 24, 21, 0.18)` |
| ホバー時 | `0 22px 42px rgba(35, 24, 21, 0.22)` |
| ロゴ・主要画像 | `drop-shadow(0 22px 34px rgba(74, 61, 43, 0.12))` |

### 罫

Levelaの罫は**両端が消える**（スプラッシュの `.levela-splash-line` がそう）。
セクション区切りには、ベタ罫より次のグラデーション罫のほうがブランドに合う。

```css
background: linear-gradient(90deg, transparent, rgba(35, 24, 21, 0.22), transparent);
height: 1px;
```

## 6. モーション

| 用途 | 時間 | イージング |
|---|---|---|
| ホバー・押下 | 180ms | `ease` |
| 出現・フェード | 500–760ms | `ease` |
| 位置・スケール移動 | 900ms | `cubic-bezier(0.22, 1, 0.36, 1)` |

`cubic-bezier(0.22, 1, 0.36, 1)`（ease-out-quint）がLevelaの動きの手触り。
速く動き出してゆっくり止まる。バウンドさせない。

出現時の定型: `opacity 0 → 1` + `translateY(14px) scale(0.98) → none`。

`prefers-reduced-motion: reduce` では移動とスケールを止め、フェードのみ残す。

## 7. チャート配色

**手法は `dataviz` スキルに従い、パレットだけこれに差し替える。**

### 明背景（対白コントラスト、すべて3:1以上）

| # | 値 | 比 |
|---|---|---|
| 1 | `#231815` | 17.31 |
| 2 | `#2F5D8C` | 6.85 |
| 3 | `#0F7B5A` | 5.25 |
| 4 | `#7A4A6E` | 6.93 |
| 5 | `#8F5A00` | 5.78 |
| 6 | `#5C7A3F` | 4.87 |
| 強調 | `#E50012` | 4.84 |

### 暗背景（対 `#171010`、すべて6:1以上）

| # | 値 | 比 |
|---|---|---|
| 1 | `#F6F2EA` | 16.82 |
| 2 | `#7FA8D4` | 7.56 |
| 3 | `#4CC79B` | 8.90 |
| 4 | `#C79BB8` | 7.88 |
| 5 | `#E8B45C` | 9.94 |
| 6 | `#A8C07E` | 9.40 |
| 強調 | `#FF6B5E` | 6.72 |

### 使い方

- **系列は最大6。** 7つ以上必要なら、そのグラフは分割すべき
- **強調色は1系列だけ。** 「見せたい1本」がないグラフは、そもそも何を言いたいのか決まっていない
- このパレットは色相で区別する設計。**輝度だけでは区別できない**（例: `#2F5D8C` と `#7A4A6E` は
  ほぼ同輝度）。凡例に頼らず**直接ラベル**を置き、隣接する塗りには1pxの `paper-0` / `#171010` の
  セパレータを入れる
- 連続量（ヒートマップ等）は `#F6F2EA → #231815` の単一グラデーション。多色にしない

## 8. やってはいけないこと

| NG | なぜ |
|---|---|
| 赤 `#E50012` を主ボタンの塗りにする | 赤が「注意」の意味を失い、全体が安く見える。主ボタンは墨 |
| 赤を1画面に2箇所以上 | どちらも重要でなくなる |
| 真鍮 `#BAA279` を明背景の文字に | 2.46:1。読めない |
| ネオン（teal / cyan / 蛍光色） | Levelaの色ではない。既存ダッシュボードの逸脱を真似しない |
| 純黒 `#000000` を文字に | Levelaの黒は温かみのある `#231815`。純黒は冷たく浮く |
| 黒の生影 `rgba(0,0,0,x)` | 影は墨を透過させる。生黒は濁る |
| `ink-400` 以下の色で本文 | 4.10:1。本文には足りない |
| グラデーションを多色で使う | Levelaのグラデーションは同系統の濃淡のみ |
| 和文の行間を1.5以下 | 詰まって読めない。1.75が下限 |
| セクション間余白を48px未満（PC） | 余白不足は最も分かりやすい安っぽさ |
| 表にない色の組み合わせを目視で採用 | 計算する。目は当てにならない |
