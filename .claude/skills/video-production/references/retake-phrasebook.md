# 修正指示の言い換え集

映像の専門用語は要らない。**見たままの不満と、欲しい状態をそのまま言葉にする**だけで意図は通る。イージングもキーフレームも言わなくていい。

守るのは 2 つ：

1. **1 回の指示に 1 テーマ。** 一文か二文投げて、返ってきたら次。詰め込むと意図が薄まり、直ってほしくない箇所まで動く。結局これが一番速い。
2. **どのシーンかを特定する。** 「シーン2の」「12秒あたりの」「最後のカードの」と場所を指定してから直す内容を言う。場所を言わない指示は全体に効いてしまう。

---

## 実際に通る指示の形

```
字幕の枠を外して、色の変化だけにして。
この文字が上の行と被ってるから、下に逃して。
締めのカードは1枚にまとめて、最後は緑のバナーで止めて。
図解は画面の左3分の1に寄せて。
シーン2の背景だけ変えて。他のシーンはそのままで。
```

最後の例のように「他は触らないで」と添えると、承認済みのシーンが巻き添えで変わるのを防げる。

---

## 「なんとなく気になる」を指示に落とす

言語化できていない違和感を、そのまま投げても直らない。左の感覚を右に翻訳する。

| 感じたこと | 投げる言葉 |
| --- | --- |
| なんか安っぽい | 「動きが同時に多すぎる。1画面で動くのは主役1つだけにして」／「色数を減らして、アクセントは1画面1箇所にして」 |
| 素人っぽい | 「シーンの切り替わりで画面が一瞬空いてる。次の要素が前の要素の退場前に出始めるようにして」 |
| 読みにくい | 「文字が小さい。1行15字以内に収めて、同時に出すのは2行までにして」 |
| 忙しない | 「1シーンあたりの表示時間を1.5倍にして。全体の尺は変えないでシーン数を減らして」 |
| 間延びしている | 「前半が長い。冒頭の導入を半分にして、結論を5秒目までに出して」 |
| 単調 | 「全部のカットが同じ長さで単調。見せ場のシーンだけ長く取って、他は詰めて」 |
| ブランドっぽくない | 「frame.mdの色とフォントが反映されていない箇所がある。仕様書と照合して直して」 |
| 印象に残らない | 「最後のフレームがすぐ消えてる。ロゴとCTAを1秒以上止めて」 |
| 説明的すぎる | 「ナレーションが説明的。冒頭で結論を言い切ってから理由を話す順番にして」 |
| 信用できなさそう | 「画面に出ている数字に出典と取得日を小さく添えて」 |

## 症状別の対処

| 症状 | 指示 |
| --- | --- |
| テロップ同士が重なる | 「この文字が被らないように下の行へ逃して」 |
| 話者の顔に図解が被る | 「図解が顔に被ってる。右半分に寄せて」 |
| 締めが冗長 | 「最初の締めカードは削って、最後はバナーで止めて」 |
| 背景と文字がケンカする | 「文字が背景に負けてる。文字の後ろに半透明の下敷きを入れて」 |
| 数字が速すぎて読めない | 「カウントアップが速い。ゆっくりにして、止まってから0.5秒残して」 |
| 日本語が変な位置で折れる | 「テロップの改行を意味の切れ目に合わせて。単語の途中で折らないで」 |
| 縦型で下の文字が隠れる | 「重要な要素を画面の上下15%から外して、中央に寄せて」 |
| 音楽が邪魔 | 「BGMがナレーションを邪魔してる。BGMを下げて」 |
| 終わり方が唐突 | 「最後がブツ切りになってる。映像も音もフェードアウトさせて」 |

## 音ハメ動画の修正

ビート同期の動画でも、修正で同期が崩れる心配は要らない。カットは近くのドラムの音へ吸着し直し、全体の尺も整えられて返ってくる。**同期のことは気にせず、見た目の不満だけ言えばいい。**

```
このテロップが被ってるから下に逃して。
最後の締めカードは1枚にまとめて。
```

---

## やらない方がいいこと

- **エフェクト名を指定する。** 「ズームで」「バウンドさせて」「イーズアウトで」は不要。指定するほど不自然になる。伝えたい内容と見せたい順番だけ言う。
- **複数テーマを 1 通に詰め込む。** 「あと字幕の色も変えて、それとBGMも差し替えて、シーン3も…」は精度が落ちる。
- **抽象的な形容詞だけを投げる。** 「もっとオシャレに」は情報量ゼロ。上の翻訳表を使う。
- **同じ指示を繰り返す。** 2 回投げて直らないなら、指示が曖昧か、`frame.md` 側の記述と矛盾している。指示ではなく仕様書を直す。

---

## なぜこれが資産になるのか

言葉で映像を直す力は、そのままディレクション能力として蓄積される。編集ソフトの操作スキルと違い、**ツールが変わっても腐らない**。これからの動画制作で価値を持つのは手先の器用さではなく、違和感を言語化する目。

ローカル完結なので何回やり直しても追加費用ゼロ。納得いくまで直せる環境があるなら、微妙な違和感を残したまま出す理由は無い。
