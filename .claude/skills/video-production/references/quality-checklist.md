# 納品前チェックリスト

**`npx hyperframes check` が通ることと、綺麗であることは別物。** check は構成の妥当性しか見ない。日本語の改行位置、文字の被り、セーフエリアのはみ出しは目でしか見つからない。

手順：

```bash
npx hyperframes check
npx hyperframes snapshot
```

書き出された静止画を **Read ツールで実際に開いて見る**。最低でも「冒頭 / 各シーンの中間 / 最後のフレーム」。動画を通しで再生するより速く、崩れは静止画に出る。

以下、優先度順。上から 3 つを潰すだけで大半の「安っぽさ」は消える。

---

## A. 日本語組版（最頻出）

| 見るところ | 基準 |
| --- | --- |
| 豆腐（□□□） | 1 つでもあれば日本語フォント未導入。`setup.md` 参照 |
| 改行位置 | 単語や熟語の途中で折れていないか。「機械学 / 習」のような分断 |
| 行頭・行末 | 行頭に `、。）」` が来ていないか（禁則処理） |
| 1 行の字数 | 横型 20 字前後、縦型 15 字以内 |
| 同時表示行数 | 短尺は 2 行まで。3 行以上は読み切る前に消える |
| 英数字の混在 | 半角英数の前後にアキがあるか。日本語と密着すると読みにくい |

改行を確実に制御したいときは、CSS で自動改行に任せず**意味の切れ目で手動改行を指定する**よう頼む。日本語は単語区切りが無いので、ブラウザ任せの折り返しは高確率で不自然な位置に落ちる。

指示例：「テロップの改行を意味の切れ目に合わせて。単語の途中で折らないで」

## B. セーフエリア

| 比率 | 避ける領域 |
| --- | --- |
| 9:16（縦型・ショート） | 上下それぞれ約 15%。SNS の UI（アカウント名、いいね、キャプション）が被る |
| 16:9 | 四辺 5% は余白として空ける |
| 1:1 | 四辺 5%。プラットフォームによっては角がトリミングされる |

重要な文字・ロゴ・数字は中央 70% に収める。**縦型は特に、下に置いたテロップがキャプションで隠れる事故が多い。**

## C. モーションの繋ぎ

- **空白フレームがゼロか。** 前の要素が消えきる前に次が出始めているか。一瞬でも画面が空くと、そこだけ素人臭くなる。プロの現場が最も気を使う箇所。
- カットの間隔が均一すぎないか。全部同じ秒数だと単調になる。
- 動きが同時に多発していないか。1 画面で主役の動きは 1 つ。
- 最後のフレームが**止め絵で 0.5 秒以上残っているか**。切れ味よく終わると情報が残らない。

指示例：「シーン2からシーン3の間で画面が一瞬空いてる。次の要素が前の要素の退場前に出始めるようにして」

## D. 可読性・色

- 本文のコントラスト比 4.5:1 以上。**背景に映像や写真が入るテロップが最も破綻しやすい。** 半透明の下敷きか、文字の縁取りで担保する。
- `frame.md` の hex と実際の色が一致しているか。ズレていたら仕様書が読まれていない可能性が高い（ファイル名と置き場所を確認）。
- 同一画面のフォントは 2 種類まで。
- アクセントカラーは 1 画面 1 箇所。使いすぎると強調が消える。

`hyperframes-creative` に `scripts/contrast-report.mjs` があり、レンダー済みフレームからコントラスト警告を機械的に出せる。写真の上に文字を置く構成では実行する価値がある。

## E. 内容・事実

- 画面に出る**数字に出典と取得日**が入っているか。実績報告は特に。
- 依頼していない機能・実績・数値が勝手に追加されていないか。
- 誤字脱字（固有名詞、社名、人名を重点的に）。
- CTA が入っているか。何をしてほしい動画なのかが最後に明示されているか。

## F. 音

- ナレーションと BGM のバランス。BGM はナレーションより十分下げる（目安 -12〜-18dB 相当）。聞き取れなければ動画としては失敗。
- 冒頭と末尾が**ブツ切りになっていないか**。フェードイン / フェードアウトが入っているか。
- 効果音が過剰でないか。1 シーンに 1 つまでが目安。
- 無音区間が不自然に長くないか。

## G. 仕様

- 指定した**尺に収まっているか**（秒数を数える）。
- 解像度・比率が指定通りか。
- ファイルサイズが投稿先の制限内か。
- 縦型・横型の両方が必要なら、両方書き出されているか。

## 修正後の再チェック

**1 箇所直すと別の箇所のレイアウトが動く。** 差分だけ見て済ませず、`snapshot` を取り直して A〜C を通しで見る。特にテキスト量が変わる修正は、後続シーンの改行位置に波及する。
