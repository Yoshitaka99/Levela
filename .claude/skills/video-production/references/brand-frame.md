# ブランド定義 — frame.md とスタイル段落

AI の動画が既視感のある仕上がりになるのは、品質が低いからではなく、**エージェントがそのブランドを知らないので世界の平均値を出してくる**から。色もフォントも動き方も平均。Canva のテンプレートが没個性になるのと構造的に同じ現象で、センスの問題ではなく「伝えるための書式が無かった」だけ。

書式を 1 度作れば、以降のすべての動画がブランドの制服を着て出てくる。完全に資産型の仕込み。

## ファイルの種類と優先順位

読み込み順は `frame.md` → `design.md` → `DESIGN.md`。**小文字の `frame.md` を推奨。**

| ファイル | 中身 |
| --- | --- |
| `DESIGN.md` | 色・フォント・言葉のトーン（Web と共通で使える汎用フォーマット） |
| `frame.md` | それに「動き方」の定義を足した動画用の上位版 |

`DESIGN.md` は HeyGen 独自規格ではなく AI デザインツール界隈で共通化しつつある形式なので、ここで作るファイルは動画以外の AI 制作物にも流用が効く。

置き場所は動画プロジェクトのフォルダ直下。置いてあるだけで機能する。**ブランドを複数持つ場合はフォルダを分ける**（同じフォルダに複数置くと混ざる）。

フロントマターに書いたトークンは「ブランドの真実」として扱われ、本文の散文は文脈として扱われる。つまり**守らせたい値はフロントマターに書く**。

## パターン 1: 自分のサイトから抽出する（最も正確）

手書きしない。URL だけ差し替えて、そのまま投げる：

```
https://あなたのサイト.com から僕のブランドのDESIGN.mdを作ってください。

ライブのHTMLと、実際に読み込まれているCSSファイルを取得して、
色のhexコードとフォント名はCSSから一字一句そのまま抜き出すこと。
スクリーンショットから色を推測するのは禁止です。
フォントは代替候補ではなく、実際に読み込まれているものを報告してください。

サイトの実際の見出しを3〜5本読んで、そこから声とトーンのルールを導いてください。

中身は絞ってください。
役割と組み合わせ付きの色を4〜6個、文字の役割を2〜3個、
余白と角丸と影の値、そして「常に〜する」「絶対に〜しない」という形のルール。
トークンの羅列にはしないでください。

最後に、それぞれの色とフォントをCSSのどこで見つけたか出典を列挙して、
出典を示せない項目は削除してください。
```

このプロンプトの設計意図：**推測を禁止し、実データから取らせ、最後に出典を言わせる。** ハルシネーションを構造的に潰す型で、動画以外の場面でも使い回せる。

出てきたら、主要な色を 2〜3 個スポイトで検証して完了。

## パターン 2: サイトが無い場合

普段の発信で使っている色コード、フォント名、口調のルールを文章で伝えて、同じ形式にまとめてもらう。note と X が主戦場なら、ヘッダー画像やサムネで使っている色をベースにすれば十分。

```
僕のブランドのDESIGN.mdを作ってください。

- ブランド名 / 発信テーマ:
- 主に使っている色（hexで）:
- フォント:
- 読者に持ってほしい印象（3語）:
- 絶対に避けたい印象（3語）:
- 口調のサンプル（自分の過去の見出しを3本）:

役割と組み合わせ付きの色を4〜6個、文字の役割を2〜3個、
余白と角丸と影の値、「常に〜する」「絶対に〜しない」のルール、という構成で。
渡していない情報を勝手に補完せず、足りない項目は質問してください。
```

## パターン 3: DESIGN.md を frame.md に拡張する

公式の変換ページ（`hyperframes.dev/design`）に `DESIGN.md` をアップロードすると、モーション言語を足した `frame.md` を返してくれる。ブランドの性格を読み取って、それに合った緩急・画面転換のスタイル・テンポを提案する仕組み。落ち着いた教育系ブランドなのに動きだけギラギラ、という事故をここで防ぐ。

手元で書く場合は、`DESIGN.md` に以下を足す。動画で決めるべきなのはこの 5 つ：

```markdown
## Motion

- 登場: 要素はどう入ってくるか（下からふわっと / 左からスライド / フェードのみ）
- 退場: どう消えるか。次の要素は前の要素が消えきる前に出始めること
- 場面転換: カットで繋ぐか、クロスフェードか、ワイプか
- テンポ: 1シーンあたりの標準秒数。緩急の付け方
- 数字の見せ方: カウントアップの速度、桁区切り、単位の置き場所
```

シャープな技術系ブランドと、温かみのあるライフスタイル系ブランドでは、映像の動き方そのものが違うはず。その違いを言語化しておく。

## 検証 — ブランドリールを 1 本作る

仕様書を読み返すより、動いているものを見た方が違和感に早く気づく。

```
/hyperframes
frame.md を渡します。
これを体現する20秒のブランドリールを1920x1080で作ってください。
ロゴとカラーパレットで始まり、タイポグラフィの見本を見せて、
このデザインシステムでUIカードを1枚組み立てて、最後はロゴで締める構成で。
すべての登場、退場、転換は frame.md のモーション言語に従ってください。
この動画は frame.md の映像化そのものです。
```

違和感があれば `frame.md` の該当箇所を直して作り直す。ここまでで専用の制作環境が完成し、以降のレシピは全部この土台の上で走る。

## frame.md が無いとき — スタイル段落

単発で作る場合や、まだブランドを固めていない場合は、依頼文にスタイル段落を添える。**書かなかったことは全部エージェントが勝手に決める**ので、この 6 要素は順番通りに埋める。

型：スタイルの名前 → hex 込みの正確なパレット → アートの方向性 → ものの動き方 → 場面転換のスタイル → 雰囲気をひと言。

```
スタイル：ミニマル・ナイトモード。
背景は#0F1115、メインテキストは#F5F7FA、アクセントは#4C8DFF、サブは#9AE6B4。
余白を広く取ったモダンなサンセリフ、細い罫線、ガラス風の半透明カード。
数字はゆっくりカウントアップ、カードは下からふわっと浮かび、グラフの線は自分で伸びていく。
場面転換はソフトなクロスフェードと横方向のワイプ。
落ち着いていて、知的で、信頼感のあるトーン。
```

差し替えて使える方向性の例：

| 方向性 | パレット例 | 動き | 雰囲気 |
| --- | --- | --- | --- |
| クリーン・ライト（BtoB / 士業） | 背景 `#FFFFFF` / 文字 `#1A1A1A` / アクセント `#2563EB` / 補助 `#64748B` | 静かなフェード、控えめなスライド | 誠実、堅実、読ませる |
| ウォーム・ドキュメンタリー | 背景 `#1C1917` / 文字 `#FAFAF9` / アクセント `#F59E0B` / 補助 `#A8A29E` | ゆっくりしたズーム、長めのクロスフェード | 人間的、余韻がある |
| ハイエナジー・ショート | 背景 `#0A0A0A` / 文字 `#FFFFFF` / アクセント `#FF3B30` / 補助 `#FFD60A` | 速いカット、大きい文字の押し出し | 勢い、断言、止まらせる |

同じ動画を横型と縦型で作るなら、**スタイル段落は共有し、レイアウトだけ指定を変える**。世界観がブレず、出せば出すほど「あの雰囲気の動画の人」という認知が積み上がる。
