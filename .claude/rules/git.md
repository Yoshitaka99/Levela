# Git・ブランチ運用規約（Levela）

## コミット
- コミットメッセージは**日本語**で書く。
- 1コミット＝レビューしやすいまとまった単位にする。
- 「何を・なぜ変えたか」が分かる文面にする。

## ブランチと push
- **main ブランチへの push は原則しない。** 作業は作業ブランチで行う。
- 作業ブランチへの push は、その都度の確認なしで進めてよい。
- ただしユーザーが明示的に「main も OK」「main まで反映して」等と指示した場合は、
  main への push・反映まで進めてよい。
- 秘密情報（`.env*` / API キー）はコミットしない。

## 本番反映
- 本番反映（Vercel）は main 反映が前提。上記 push 方針に従う。
- 破壊的変更・本番影響のある操作は、上記の許可範囲内で進める。
