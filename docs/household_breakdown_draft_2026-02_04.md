# 家計表 分解案 2026年2月-4月

作成日: 2026-05-20

目的:

- あまた法律事務所の家計表原本へ書き込む前の整理。
- 収支がマイナスにならないよう、生活実態として説明しやすい範囲で分類する。
- 住信SBI明細だけではデビット利用先の店名が出ないため、判読できる項目と未分類生活費を分ける。

重要な考え方:

- 銀行口座の「出金合計」には、現金引出、PayPay振替、目的別口座への振替、デビット決済などが混在している。
- そのため、銀行の出金合計をそのまま家計表の支出合計にすると、実生活の支出より大きく見えたり、収支が不自然にマイナスになる可能性がある。
- 家計表には「その月の生活費として使った金額」を入れる。
- 口座内振替や翌月家賃用の一時移動は、原則として生活支出ではなく資金移動として扱う。

## 確認したい点

原本に書き込む前に、以下だけ確認できると精度が上がる。

1. 家賃の実額は2月・3月・4月とも70,000円扱いでよいか。
2. 2月・3月の電話代を7,000円概算でよいか。明細があれば差替。
3. 食費・日用品・交通費・交際費・娯楽費は、SBIデビット明細の詳細店名がないため按分でよいか。
4. 4月の日研グループ健康保険組合44,968円は「税金・国保・国民年金」欄に入れるか、「その他（健康保険）」欄に入れるか。

## 提出時の補足文案

> 家計表は住信SBIネット銀行の入出金明細をもとに作成しています。デビット利用分については明細上で店舗名等の詳細が確認できないものがあるため、生活費として食費・日用品・交通費等へ按分し、不明分は「その他（生活費・デビット等）」に整理しています。ゆうちょ銀行については、令和8年1月21日以降、現在まで取引はありません。
