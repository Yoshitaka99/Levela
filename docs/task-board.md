# タスクボード（task-board）

司令塔とサブエージェントが「今何をやるか / 何が終わったか」を共有する場所です。
**着手前に必ず読む。完了ごとに必ず更新する。**

## 運用ルール
- タスクは `TASK-XXX` で採番。1タスク＝レビュー可能な単位に分割する。
- 状態は「未着手 → 進行中 → レビュー中 → 完了」で動かす。
- 進行中タスクは原則1〜数件に絞り、完了したら次を引き上げる。

## ステータス凡例
- 🔲 未着手
- 🚧 進行中
- 👀 レビュー中
- ✅ 完了

## タスク記述テンプレート
```
- [ ] TASK-XXX: <タイトル>
  - 関連要求: REQ-XXX
  - 担当の流れ: researcher → planner → implementer → tester → reviewer
  - 受け入れ条件:
    - [ ] npm run lint / npm run build が通る
    - [ ] <機能固有の条件>
  - メモ:
```
