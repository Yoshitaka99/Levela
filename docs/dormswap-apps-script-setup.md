# Apps Script 導入手順

## 1. Apps Script を開く

対象の Google スプレッドシートを開く。

メニューから `拡張機能` → `Apps Script` を開く。

## 2. コードを貼り付ける

Apps Script エディタで、既存の `Code.gs` に `apps-script/Code.gs` の内容を貼り付ける。

`appsscript.json` を表示できる設定にしている場合は、`apps-script/appsscript.json` の内容も反映する。

## 3. 保存する

プロジェクト名は例として以下にする。

`dormswap 営業管理システム`

## 4. スプレッドシートを再読み込みする

スプレッドシートに戻ってブラウザを再読み込みする。

メニューに `🔧 dormswap` が表示される。

## 5. カレンダー連携を実行する

`▶ セットアップ` タブの `C7` に連携したい Google カレンダーのメールアドレスを入れる。

その後、メニューから以下を実行する。

`🔧 dormswap` → `🔗 カレンダー連携セットアップ`

初回は Google の権限許可画面が出る。

許可すると、以下が自動で作られる。

- `設定`
- `アポ原本`
- `顧客管理`
- `KPI分析`
- 1時間ごとの自動同期トリガー

## 6. 日常運用

カレンダー予定は自動で `アポ原本` に入る。

営業担当は `顧客管理` で以下を更新する。

- 流入経路
- 流入
- 着席
- 2回目/実施後ステータス
- 着金予定日
- 決着日
- 成約プラン
- 支払方法
- 成約金額
- 失注理由
- 保留理由
- Lステ顧客ID
- メモ

`KPI分析` は `顧客管理` の値を見て自動更新される。

## 担当者コピーを作る

マスターシートで以下を実行する。

`🔧 dormswap` → `👥 担当者コピーを作成`

担当者のカレンダーメールと担当者名を入力すると、その担当者用のコピーが作成される。

コピー先のスプレッドシートで、担当者本人が `🔗 カレンダー連携セットアップ` を実行する。

## よくあるエラー

### カレンダーが見つからない

原因:

- メールアドレスが違う
- カレンダー共有権限がない
- 担当者本人ではなく別アカウントで実行している

対応:

連携したいGoogleアカウントで開き直して、再度セットアップする。

### メニューが出ない

対応:

スプレッドシートを再読み込みする。

それでも出ない場合は Apps Script の `onOpen` が保存されているか確認する。

### KPIが更新されない

対応:

`🔧 dormswap` → `📊 KPIを再生成` を実行する。

それでも変わらない場合は `顧客管理` のステータス列がプルダウン候補と一致しているか確認する。
