# オロチーム モチベーション動画 台本

- **タイトル案**: 「なぜ、ここに来た。」／ 別案「一瞬の楽か、一生の後悔か」
- **尺**: 本編 2分40秒（＋60秒ショート版を後半に記載）
- **用途**: 朝礼・月初キックオフ・Slack共有・新メンバーオンボーディング
- **キーメッセージ**: 成約率にこだわる／成約数にこだわる／なぜLevelaに来たのか
- **トーン**: 前半は静か・低音。中盤から畳みかけ。ラストは全員のコール。

## 2. 本編台本（2分40秒）

### ① 沈黙と問い — 0:00 - 0:20

| 項目 | 内容 |
|---|---|
| 映像 | 真っ暗な画面。誰もいないオフィス。机の上のヘッドセット。消えたPCモニタ。カットは長め（3〜4秒）。 |
| BGM | 無音 → 0:08から低いピアノ単音（ドローン）フェードイン |
| SE | 0:00 心臓の鼓動を1回だけ（ドンッ） |

**テロップ（黒背景・白ゴシック・1行ずつ）**
```
今日、
あなたは何本 取ったか。
```

**ナレーション（低音・ゆっくり・間を1秒ずつ取る）**
> 数字は、覚えている。
>
> あなたが、あの日どれだけやったか。
>
> ……そして、どれだけ逃げたかも。

### ② なぜLevelaに来たのか — 0:20 - 0:55

| 項目 | 内容 |
|---|---|
| 映像 | 面接の日／入社初日の写真、初めて名刺を持った手元、ロープレしている姿。粗い手ブレ映像＋モノクロ。 |
| BGM | ピアノにストリングス薄く重なる |
| 編集 | ナレーションの「なぜ」でフラッシュ（白1フレーム） |

**テロップ**
```
思い出せ。
なぜ、Levelaに来た。
```

**ナレーション**
> 楽をするために、ここに来たのか。
>
> 違うだろ。
>
> 変わりたかったんだろ。
>
> 「このままの自分で終わりたくない」
> そう思ったから、ここに来たんだろ。
>
> あの日のあなたは、今日のあなたを見て、何て言う。

**テロップ（畳みかけ・1秒ごとに切替）**
```
変わりたかった
勝ちたかった
稼ぎたかった
認められたかった
```

### ③ 数字は嘘をつかない — 0:55 - 1:25

| 項目 | 内容 |

**テロップ**
```

```

**ナレーション（少し強く）**
> 「頑張ってます」は、数字じゃない。
>
> 「忙しいです」も、数字じゃない。
>
> 残るのは、成約率と、成約数だけだ。
>

>
> あと1本。
> その1本を取りにいくかどうかで、
> 半年後のあなたは、別人になる。

## 4. 制作メモ

### ナレーション
- 収録は**ゆっくり・低め**で。編集で詰めた方が迫力が出る。読点ごとに0.5〜1秒の間を取って読む。
- 前半は「語りかけ」、④から「問い詰め」、⑤で「最大」、⑥で「静かな確信」に戻す。この落差が効く。
- 読み手はマネージャー本人が推奨（借り物の声より圧倒的に刺さる）。

### テロップ
- フォント: 太いゴシック（例: Noto Sans JP Black / 源ノ角ゴシック Heavy）
- 基本は**白文字＋黒背景**。強調のみ赤。3色以上使わない。
- 1画面1メッセージ。長い文は必ず改行で割る。

### 映像素材（社内で撮る場合のショットリスト）
1. 誰もいない朝のオフィス（引き）
2. ヘッドセット／受話器のクローズアップ
3. 架電中の横顔・手元
4. ロープレ風景（詰められている表情も入れる）
5. ホワイトボード／ダッシュボードの数字
6. 立ち上がる、拳を握る等の動作
7. 全員の集合カット（ラスト用）
- 前半は**モノクロ＋粒子ノイズ**、⑥だけカラーに戻すと転換が伝わる。

### BGM
- 前半: 静かなピアノ / アンビエント
- 後半: エピック系オーケストラ（トレーラー音源）
- 素材は必ず商用利用可のものを（Artlist / Epidemic Sound / DOVA-SYNDROME 等）。YouTube上の音源をそのまま抜くのはNG。

### 編集ソフト
- CapCut / Premiere Pro どちらでも可。テロップ主体なので CapCut でも十分作れる。
- キーとなるのは「無音の間」。1.5秒の沈黙を怖がらずに入れる。
