# 家計表以外の必要アクション 2026-05-23

## A. 本人が動く必要があるもの

### 1. 東京の住民票原本

- 役所またはコンビニ交付で取得。
- 条件:
  - 本籍あり
  - 世帯主・続柄あり
  - 筆頭者あり
  - 世帯全員記載
  - 個人番号・住民票コードなし
- 取得後、原本をあまた法律事務所へ郵送。

## B. 電話またはログイン確認が必要なもの

### 2. 大同火災

公式窓口:

- お客さま相談センター: `0120-671-071`
- 受付: 平日 9:00-17:00（土日祝・12/31-1/3除く）
- 公式問い合わせフォーム: `https://contact.daidokasai.co.jp/`
- 参考: 大同火災公式「お問い合わせ窓口」 `https://www.daidokasai.co.jp/support/`

確認事項:

- 契約が解約済みか
- 解約日
- 解約返戻金の有無・金額
- 未払い保険料の有無
- 保険証券・解約証明・返戻金明細を再発行できるか

電話で言う内容:

```text
以前加入していた自動車保険について、破産手続きで提出が必要なため確認したいです。
契約者は田仲由敬です。
解約日、解約返戻金の有無、未払い保険料の有無、証券または解約関係書類の再発行が可能か確認したいです。
```

フォームで送る場合の文案:

```text
以前加入していた自動車保険について、破産手続きで弁護士へ提出するため確認をお願いします。
契約者は田仲由敬です。

確認したい事項は以下です。
1. 契約が解約済みか
2. 解約済みの場合の解約日
3. 解約返戻金の有無と金額
4. 未払い保険料の有無
5. 保険証券、解約証明、返戻金明細、支払状況が分かる書類の再発行可否

本人確認等が必要な場合はご案内ください。
```

### 3. 東京海上日動

公式窓口:

- 自動車保険・バイク保険カスタマーセンター: `0120-153-381`
- 受付: 平日・土日祝 9:00-18:00（年末年始除く）
- 公式ページ: `https://www.tokiomarine-nichido.co.jp/support/contact/auto381.html`
- 参考: 解約・更新停止は契約者本人から代理店またはカスタマーセンターへ連絡する扱い。

確認事項:

- 2024年7月26日以降に契約が継続していたか
- 解約済みなら解約日
- 別口座・振込用紙等で支払いがあったか
- 解約証明または支払履歴が出せるか

電話で言う内容:

```text
以前の自動車保険について、破産手続きで提出が必要なため確認したいです。
2024年7月26日以降に契約が継続していたか、解約済みなら解約日、支払い履歴、解約関係書類の再発行可否を確認したいです。
```

電話で追加して聞くこと:

```text
手元では琉球銀行から2024年7月26日まで支払いが確認できています。
それ以降に契約が残っていたか、別の口座・クレジットカード・振込用紙で支払いが続いていたかを確認したいです。
書類として提出できる支払履歴、解約証明、契約内容確認書のようなものが発行可能かも教えてください。
```

### 4. 楽天モバイル

公式確認先:

- my 楽天モバイル: `https://portal.mobile.rakuten.co.jp/my-rakuten-mobile`
- 公式説明では、未払い料金は my 楽天モバイルの「利用料金」画面で確認する。
- 参考: 楽天モバイル公式「未払い料金の発生からご利用停止・契約解除まで」 `https://network.mobile.rakuten.co.jp/guide/payment/invoice/unpaid/`

確認事項:

- 契約電話番号
- 未払い料金の有無
- 未払いがある場合の金額・対象月
- 債権移管済みか

ログイン後に見る場所:

```text
my 楽天モバイルへログイン
→ 利用料金
→ 月を切り替えて、請求ステータスが「未払い」「確定」どちらか確認
→ 契約電話番号も契約情報画面で確認
```

弁護士へ伝える用のメモ形式:

```text
楽天モバイルについて確認しました。
契約電話番号: [番号]
未払い: [なし / あり]
未払いがある場合: [対象月] [金額]
債権移管の表示・通知: [なし / あり / 不明]
```
