# Warp × Claude × Codex 初心者ガイド

Warp（ワープ）というターミナルアプリの中で、**Claude Code** と **Codex** を使うための入門ガイドです。
「そもそも何がどれなのか分からない」「画面が見づらい」「操作が分からない」を、順番に解消していきます。

> **超入門の人へ**：「フォルダって何？」「このキーを押したら何が起きるの？」というレベルなら、
> まず次の「超入門編」から読んでください。ここが分かると一気にラクになります。

---

## 超入門編：ターミナルとフォルダの基礎

Claude や Codex を触る前に、土台の「ターミナルとは何か」を先に押さえます。ここが本丸です。

### A. 画面の見方（何が表示されているの？）

ターミナルの1行は、だいたいこうなっています。

```text
user@pc  ~/Levela  $ █
 └─だれ─┘ └─今いる場所─┘ ↑ここに文字を打つ（█＝カーソル）
```

- `$`（または`%`）の**右側**に、あなたがコマンドを打ちます。
- `$` の**左側**は「今どのフォルダにいるか」の表示。**自分の現在地**です。
- Enterを押すと、打った命令が**実行**されます。

> 大事な考え方：ターミナルは「**今いるフォルダ**に対して命令する」道具。だから常に「今どこにいるか」を意識します。

### B. フォルダ（ディレクトリ）とは

パソコンの中身は「フォルダの入れ子」でできています。ターミナルでは**フォルダ＝ディレクトリ**と呼びます（同じ意味）。

```text
自分の家（ホーム ~）
├── Levela          ← プロジェクトのフォルダ
│   ├── app         ← この中にコードのファイル
│   ├── docs        ← この中に説明ファイル（今読んでるやつもここ）
│   └── README.md
└── Downloads
```

- 「今どのフォルダにいるか」で、見えるファイルや実行結果が変わります。
- 引っ越し（移動）しながら作業する、とイメージすればOK。

### C. 最初に覚える“5つのコマンド”（打つと何が起きる）

この5つだけで「見る・動く・作る」ができます。実際に打って確かめてください。

| 打つもの | 読み | 押すと何が起きる |
| --- | --- | --- |
| `pwd` | ピーダブリューディー | **今どこにいるか**を表示（現在地の確認） |
| `ls` | エルエス | 今いるフォルダの**中身の一覧**を表示 |
| `cd フォルダ名` | シーディー | そのフォルダの**中に入る**（移動する） |
| `cd ..` | | **1つ上**のフォルダに戻る |
| `mkdir 名前` | メイクディレクトリ | 新しいフォルダを**作る** |

例：Levelaの中の docs を覗いて、また戻る流れ 👇

```bash
pwd            # 今どこ？ → /home/user/Levela と出る
ls             # 中身を見る → app  docs  README.md ... と出る
cd docs        # docs の中に入る
ls             # docs の中身が見える
cd ..          # 1つ上（Levela）に戻る
```

> つまずき対策：`ls` で見えないファイルを `cd` しようとすると「そんなの無い」と怒られます。
> **迷ったら `pwd` で現在地、`ls` で中身**。この2つが“地図”です。

### D. キーを押すと何が起きる（操作の正体）

「これ押したら何が起きるの？」の答え一覧。ここが分かると怖くなくなります。

| キー | 押すと何が起きる |
| --- | --- |
| **Enter** | 打った命令を**実行**する |
| **↑ / ↓（上下矢印）** | **前に打ったコマンド**を呼び出す（打ち直し不要） |
| **Tab** | 入力の**続きを自動補完**（`cd doc` まで打って Tab → `docs/`） |
| **Ctrl + C** | 今動いている処理を**中断・キャンセル**する（止めたい時の非常ボタン） |
| **Ctrl + L**（Warpは`⌘+K`） | 画面表示を**きれいにする**（履歴は消えない） |
| **⌘ + C / ⌘ + V** | コピー / 貼り付け（Win/Linuxは `Ctrl+Shift+C/V`） |

> 覚えておくと安心：**うまくいかない・固まった → `Ctrl + C`**。これで大抵の暴走は止まります。

### E. Warpならではの“やさしさ”

普通のターミナルより、Warpは初心者に親切です。

- **1コマンド＝1つの箱（ブロック）** にまとまるので、「どこから結果か」が一目で分かる。
- コマンドを覚えていなくても、**日本語で聞けば教えてくれる**（後述のWarp内蔵AI）。
- 打ち間違いはやり直せます。**間違えても壊れない**ので、どんどん試してOK。

ここまで分かれば、この先の Claude / Codex は「同じターミナルの中で、AIに日本語で頼むだけ」になります。

## 0. まず全体像（何がどれ？）

登場するものは大きく3つ。役割が別々です。

| 名前 | 正体 | ざっくり役割 |
| --- | --- | --- |
| **Warp** | ターミナルアプリ本体 | 文字を打ってPCに指示する「作業場」。この中で他の道具を動かす。 |
| **Warp内蔵AI（Agent Mode）** | Warpに最初から入っているAI | 「これどうやるの？」を日本語で聞くと、コマンドを提案・実行してくれる。 |
| **Claude Code** | Anthropic製のAIコーディング道具 | `claude` と打つと起動。コードを書く・直す・調べるのが得意な相棒。 |
| **Codex** | OpenAI製のAIコーディング道具 | `codex` と打つと起動。Claudeと似た相棒（別会社版）。 |

ポイント：

- **Warpは「箱」**、Claude と Codex は「箱の中に入れて使う道具」です。
- Claude と Codex は**ほぼ同じ用途の別ブランド**。両方入れておいて、好きな方に頼めばOK。
- 迷ったら「Warpを開く → `claude` か `codex` と打つ → 日本語で頼む」だけ覚えれば動きます。

```text
┌──────────────── Warp（ターミナル＝作業場）─────────────────┐
│                                                           │
│  $ claude   ← これで Claude Code が起動                     │
│  $ codex    ← これで Codex が起動                           │
│                                                           │
│  ⌘+I など   ← Warp内蔵AIに日本語で質問                      │
│                                                           │
└───────────────────────────────────────────────────────────┘
```

## 1. いちばん最初にやること（見やすさの改善）

「見づらい」はやる気に直結するので、最優先で直します。すべて **Warpの設定（Settings）** で変えられます。

設定の開き方：

- Mac: `⌘ + ,`（コマンド＋カンマ）
- Windows / Linux: `Ctrl + ,`

### 1-1. 文字を大きく・読みやすく

`Settings → Appearance（外観）` を開いて、次を調整します。

- **Font（フォント）**: 等幅フォントにする。おすすめは `Hack Nerd Font` `JetBrains Mono` `MesloLGS NF` など。
  - AIツールはアイコン（絵文字みたいな記号）を表示するので、**「Nerd Font」系**を選ぶと記号が化けません。
- **Font size（文字サイズ）**: 迷ったら **14〜16** から。大きめが疲れません。
- **Line height（行の高さ）**: `1.2〜1.5` にすると行間が空いて読みやすい。

### 1-2. 配色（テーマ）を変える

`Settings → Appearance → Themes` で色を選べます。

- 明るい部屋 → ライトテーマ（白背景）
- 暗い部屋・夜 → ダークテーマ（黒背景）
- 目が疲れるなら **コントラスト（明暗差）が強すぎない**テーマを選ぶ。

### 1-3. 「ブロック」で見やすくなる仕組みを理解する

Warp最大の特徴が **Blocks（ブロック）** です。

- 1回のコマンドと、その結果が **1つの箱（ブロック）** にまとまります。
- どこからどこまでが1つの操作か、色分け・区切りで**ひと目で分かる**のが普通のターミナルとの違い。
- ブロックにマウスを乗せると、右上に「コピー」「共有」などのボタンが出ます。

> つまずきやすい点：長い出力が流れて迷子になったら、ブロック単位でスクロールを戻せば「どのコマンドの結果か」を追えます。

### 1-4. 入力欄を下に固定して迷子を防ぐ

`Settings → Appearance → Input Position` を **「Pin to bottom（下に固定）」** にすると、
入力する場所が常に画面下で安定し、「今どこに打てばいいの？」が無くなります。

## 2. Warp内蔵AI（Agent Mode）の使い方

「コマンドを覚えていない」初心者に一番やさしいのがコレです。

### 起動のしかた

- 入力欄に**日本語でそのまま質問を打つ**か、`⌘ + I`（Windows/Linuxは `Ctrl + I`）でAI入力に切り替えます。
  - ※ショートカットはWarpのバージョンで変わることがあるので、動かなければ `Settings → Keyboard Shortcuts` で「AI」を検索。

### 使い方の例

```text
このフォルダのファイル一覧を見せて
git の変更を取り消したい
npm のエラーの意味を教えて
```

- AIが**コマンドを提案**してくれます。
- 内容を確認して **Enterで実行**、いらなければ無視。
- **勝手に全部実行はされない**ので、初心者でも安全です（提案 → あなたが承認、の流れ）。

> コツ：「何をしたいか」を日本語で書けばOK。正しいコマンド名を知らなくて大丈夫です。

## 3. Claude Code の使い方

### 3-1. 起動と終了

```bash
claude          # 起動（対話モードに入る）
```

- 起動すると入力待ちになるので、**日本語で頼みたいことを打つ**だけ。
- 終了は `Ctrl + C` を2回、または `/exit`。

```text
> このプロジェクトの構成を説明して
> app/ の中でバグっぽい所を探して
> README を分かりやすく書き直して
```

### 3-2. スラッシュコマンド（最初に覚える5つ）

入力欄で `/` を打つと一覧が出ます。特に使うのはこれ。

| コマンド | 何をする |
| --- | --- |
| `/help` | 使えるコマンドの一覧・ヘルプ |
| `/clear` | 会話をリセット（話が長くなって迷子になったら） |
| `/model` | 使うモデルを切り替える |
| `/init` | プロジェクトの説明ファイル（CLAUDE.md）を作る |
| `/exit` | 終了する |

### 3-3. 動作モード（安全レベル）を切り替える

`Shift + Tab` を押すたびにモードが切り替わります。初心者はここが分かると一気に安心できます。

- **通常モード**: ファイルを変更する前に「変更していい？」と聞いてくる（＝安全）。
- **Plan（計画）モード**: いきなり手を動かさず、**まず計画を提示**してくれる。大きめの作業の前におすすめ。
- **自動承認モード**: いちいち聞かずに進める（速いが、慣れてから）。

> 初心者おすすめ：**通常モード or Planモード**。「勝手に変えられるのが怖い」を防げます。

### 3-4. 頼み方のコツ

- **具体的に**：「直して」より「`app/page.tsx` のボタンが押せないので原因を調べて直して」。
- **1回に1テーマ**：あれもこれもより、1つ終わってから次へ。
- **ファイル名を添える**：`@` を打つとファイル名を補完できます（例：`@README.md を要約して`）。

## 4. Codex の使い方

Codex は OpenAI版の相棒。Claude Codeと**操作感はよく似ています**。

### 4-1. 起動

```bash
codex           # 対話モードで起動
```

- 起動後は**日本語でそのまま依頼**。
- 終了は `Ctrl + C` を2回、または `/exit`。

### 4-2. コマンドを実行せず答えだけ欲しいとき

```bash
codex exec "このスクリプトが何をしているか説明して"
```

- `exec` を付けると**対話に入らず、その場で1回だけ**答えてくれます。

### 4-3. 承認モード（勝手に実行させない）

Codexにも「どこまで自動でやらせるか」の設定があります。

- **提案を確認してから実行**（初心者はこれ）
- **自動で実行**（慣れてから）

起動後の画面の案内、または `/help` で現在のモードと切り替え方法を確認できます。
「怖い」と感じるうちは**確認モード**にしておけば安全です。

## 5. Claude と Codex、どっちを使う？

結論：**どちらでもよい。両方に同じことを頼んで、良かった方を採用**するのが実は一番かしこい使い方です。

| こんなとき | おすすめ |
| --- | --- |
| とりあえず動かしたい | どちらでもOK。慣れている方 |
| 説明が丁寧な方がいい | 2つに同じ質問をして読み比べる |
| 答えが怪しいと感じた | もう片方に「この答え合ってる？」と聞く |

> 使い分けに悩む時間より、**両方に投げて比べる**方が速くて確実です。

## 6. よく使うショートカット早見表

Warp本体のショートカット（Macは`⌘`、Windows/Linuxは`Ctrl`に読み替え）。

| 操作 | Mac | 説明 |
| --- | --- | --- |
| 設定を開く | `⌘ + ,` | 見やすさ・テーマの変更 |
| 新しいタブ | `⌘ + T` | 作業を分ける |
| コマンド検索 | `⌘ + P` | 過去に打ったコマンドを探す |
| 画面をきれいに | `⌘ + K` | 表示をクリア（履歴は残る） |
| AIに切り替え | `⌘ + I` | Warp内蔵AIに質問 |
| コピー | `⌘ + C` | ブロックを丸ごとコピー可 |

Claude / Codex の中でのショートカット：

| 操作 | キー | 説明 |
| --- | --- | --- |
| モード切替 | `Shift + Tab` | 安全レベルを変える（Claude） |
| 中断 | `Esc` | AIの作業を止める |
| 終了 | `Ctrl + C` ×2 | ツールを抜ける |

> ショートカットが効かない時は、Warpの `Settings → Keyboard Shortcuts` で調べ直せます（キーワード検索できます）。

## 7. つまずきポイント Q&A

**Q. `claude` / `codex` と打っても「command not found」と出る**
→ まだインストールされていない可能性大。まずは Warp内蔵AI（`⌘+I`）に「Claude Code をインストールしたい」「Codex CLI をインストールしたい」と日本語で聞くと、手順を出してくれます。

**Q. 英語ばかりで読めない**
→ 「これからは日本語で答えて」と最初に伝えればOK。以降は日本語で返ってきます。

**Q. 勝手にファイルを変えられそうで怖い**
→ Claudeは `Shift + Tab` で **通常モード（変更前に確認）** に。Codexも**確認モード**にしておけば、実行前に必ず止まります。

**Q. 会話がごちゃごちゃしてきた**
→ Claudeなら `/clear`、Codexも同様にリセット。区切りたい作業ごとにリセットすると迷子になりません。

**Q. 画面がやっぱり見づらい**
→ セクション1に戻る。①フォントサイズ14〜16 ②行間1.2〜1.5 ③Nerd Font ④入力欄を下に固定、の4点で大きく改善します。

## 8. まずはこれだけ（最短の始め方）

1. Warpを開く。
2. `⌘ + ,` で設定を開き、フォントサイズを **15**、行間を **1.3** にする。
3. 入力欄に `claude`（または `codex`）と打ってEnter。
4. 「**これからは日本語で答えて。まずこのフォルダが何のプロジェクトか説明して**」と頼む。
5. 慣れてきたら `Shift + Tab` でモードを試す。

これで「使い方が分からない」「見づらい」はひと通り解消できます。分からない用語が出たら、そのまま Warp内蔵AI か Claude/Codex に「〇〇ってどういう意味？」と聞けば教えてくれます。
