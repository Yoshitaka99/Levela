# Lステップ タグ抽出・セグメント判定

## 目的

Lステップの友だちリストをスプレッドシート経由で読み込み、タグの付き方を集計して「誰がどの層か」を判断できるようにするツールです。書き込みは一切しません（読み取り専用）。

## URL

- 画面: `/lstep-tags`
- API: `/api/lstep-tags`

`noindex` 設定のため検索エンジンには載りません。

## 準備

1. Lステップの管理画面で友だちリストをCSVエクスポートする。
2. そのCSVをGoogleスプレッドシートに取り込む（インポート、または貼り付け）。
3. スプレッドシートの共有設定を「リンクを知っている全員（閲覧者）」にする。
   - 公開CSV（gviz）で読むため、この設定が無いと読み込めません。
   - 逆に言うと**リンクを知っていれば誰でも中身を見られる状態**になるので、個人情報の扱いに注意してください。
4. `/lstep-tags` の「設定」タブでスプレッドシートURLを貼り付けて保存する。

接続情報はブラウザの localStorage に保存されるため、次回以降は自動で読み込まれます。
共通の接続先を固定したい場合は環境変数で指定できます。

## 環境変数（任意）

| 変数名 | 説明 | 既定値 |
| --- | --- | --- |
| `LSTEP_SPREADSHEET_ID` | 既定のスプレッドシートID（URLでも可） | 空 |
| `LSTEP_SHEET_NAME` | 既定のシート名。空欄なら先頭シート | 空 |
| `LSTEP_RANGE` | 読み込み範囲 | `A1:CV5000` |

画面の設定タブで指定した値のほうが優先されます。

## 対応しているシートの形

ヘッダー行は先頭8行の中から自動検出するため、上に説明行やタイトル行があっても動きます。
列は見出し名から自動判定します。

| 項目 | 判定に使う見出しの例 |
| --- | --- |
| 名前 | 友だち登録名 / 表示名 / 名前 / 氏名 |
| 登録日 | 登録日時 / 追加日 / 友だち追加日 |
| 流入経路 | 流入経路 / 経路 / 媒体 |
| ステータス | ステータス / 状態 / ブロック |

タグは次の2形式に対応しています（混在も可）。

- **1列にまとめる形**: 見出しが「タグ」で始まる列。`,` `、` `|` 改行で区切って複数タグとして扱います。
  タグ名に `/` が含まれることがあるため、`/` では分割しません。
- **タグごとに列を持つ形**: 見出しがタグ名で、中身が `○` `✓` `1` `TRUE` `あり` などのマークだけの列。
  `×` は「付いていない」として扱います。

自動判定がずれた場合は、シートの見出しを分かりやすい名前に変えるのが一番確実です。
API を直接叩く場合は `nameColumn` `registeredAtColumn` `sourceColumn` `statusColumn` `tagColumns` に0始まりの列番号を渡して上書きできます。

## 画面の見方

- **概要**: 友だち総数・タグ種類数・タグ付与率、よく使われているタグ、タグの併用パターン、流入経路別の集計。
  - 併用パターンの `lift` は「独立していた場合の何倍一緒に付いているか」。1.2倍以上のものだけ表示します。
    `lift` が高い組み合わせほど、実際の導線としてセットで動いていることを意味します。
- **タグ一覧**: 全タグの人数と比率。タグ名をクリックすると抽出条件に入ります。
- **セグメント判定**: ルールに従って友だちを1人1セグメントに振り分けます。
- **抽出**: タグのAND/OR/除外、流入経路、名前で絞り込み、CSV出力。

## セグメント判定ルール

上から順に判定し、**最初に当てはまったルール**のセグメントになります。どれにも当てはまらない人は「未分類」です。
そのため、優先度の高いもの（成約など）を上に置いてください。

各ルールは3種類の条件を持ちます。

- **いずれかを含む**: どれか1つでも当てはまればOK
- **すべて含む**: 全部当てはまる必要がある
- **含まない**: 1つでも当てはまったら除外

キーワードはタグ名の**部分一致**です（全角半角と大文字小文字は吸収します）。
`セミナー参加` と書いておけば `セミナー参加_8月度` にも当たります。

初期ルールは一般的なファネルを想定したたたき台なので、実際のタグ名に合わせて画面上で編集してください。
編集内容はブラウザに自動保存されます。「初期値に戻す」でいつでも戻せます。

## 制限

- 読み取り専用です。Lステップ側やシートには書き込みません。
- 抽出結果の画面表示は先頭300件です。全件が必要な場合はCSV出力を使ってください。
- 併用パターンの分析はデータが10件以上ある場合のみ動きます。
