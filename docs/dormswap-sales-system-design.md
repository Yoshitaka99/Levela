# dormswap 営業管理システム 設計メモ

## ゴール

Googleカレンダーに入っている営業アポをスプレッドシートへ自動同期し、営業担当が顧客ごとのステータスを更新すると、KPIへ自動反映される状態を作る。

さらに、テンプレートをコピーしてGoogleカレンダーのメールアドレスを入れるだけで、他の営業担当も同じ仕組みを使えるようにする。

## 現状確認

確認したブックには以下のタブがある。

- `▶ セットアップ`
- `シート1`
- `シート2`
- `目標`
- `KPI分析`

`▶ セットアップ` は、カレンダーメールを入力してメニューから連携セットアップを実行する導線になっている。

一方で、確認時点ではブック内に数式は入っておらず、`KPI分析` の数値も固定値だった。したがって、現状は完成済みの自動集計システムではなく、完成イメージに近い状態。

## 推奨構造

### `▶ セットアップ`

担当者が触る初期設定画面。

- カレンダーID/Googleメール
- 連携ステータス
- 最終同期日時

### `アポ原本`

Googleカレンダーから同期した予定だけを保持する原本。

ここは人間が編集しない。再同期で上書きされてもよいデータだけを置く。

主キーは `eventId`。

### `顧客管理`

営業担当がステータスを更新するメイン画面。

カレンダーから入る項目と、営業が手で更新する項目を同じ行に持たせる。ただし、再同期時は手入力項目を保持する。

主キーは `eventId`。

### `KPI分析`

`顧客管理` を正として数式で集計する。

ステータスを変えるだけで、以下が自動更新される。

- 総アポ数
- 着席数
- 着席率
- 成約数
- 成約率
- 飛び
- キャンセル
- 失注
- 保留
- 月別集計
- 担当者別集計

### `設定`

プルダウン候補を管理する。

- ステータス
- 流入経路
- 流入
- 着席
- 成約プラン
- 支払方法
- 失注理由
- 保留理由

## 権限上の重要ポイント

Googleの仕様上、メールアドレスを入力しただけで他人のGoogleカレンダーを勝手に読むことはできない。

連携できるのは次のどちらか。

1. そのシートを操作している本人が、自分のカレンダー連携を許可する
2. 管理者アカウントに各担当者のカレンダー閲覧権限を共有し、管理者が一括同期する

現行のセットアップタブは 1 の方式に向いている。

## 担当者追加フロー

推奨フロー:

1. マスターのスプレッドシートを開く
2. `🔧 dormswap` → `👥 担当者コピーを作成`
3. 担当者のGoogleカレンダーメールを入力
4. 担当者名を入力
5. コピーされたスプレッドシートURLを担当者に渡す
6. 担当者本人がコピー先で `🔗 カレンダー連携セットアップ` を実行
7. 初回権限許可後、1時間ごとの自動同期が始まる

注意:

コピー作成までは管理者ができるが、本人のカレンダー権限承認は担当者本人の実行が必要。

## 実装ファイル

- `apps-script/Code.gs`
- `apps-script/appsscript.json`

Google Sheets の Apps Script エディタへ貼り付けて使う。

## 運用ルール

`アポ原本` は編集しない。

営業担当が触るのは基本的に `顧客管理`。

カレンダー予定名からお客様名を推定するため、予定タイトルは以下のように揃えると精度が上がる。

- `山田 太郎様 個別相談`
- `【面談】山田 太郎様`
- `お客様名: 山田 太郎様`

説明欄に `お客様名: xxx` がある場合は、タイトルより説明欄を優先する。
